# 罕见事件分析应用：给定时段首次缓存溢出概率估计

一个**从零实现**的教学应用：在虚构的离散时间排队系统上，估计给定容量 `C`、
时域 `T` 内**首次溢出**（某时隙 `q + a > C`）的概率，并对照两种估计方式：

- **普通模拟（Crude Monte Carlo）**：直接按名义测度抽样，稀有事件常零命中；
- **重要抽样（Importance Sampling, IS）**：指数倾斜到达机制，按路径似然比加权重加权。

> 所有模型均为**虚构的到达流与服务过程**，仅用于方法教学与对照，
> **不代表任何真实系统，也不构成容量或可靠性保证**。
> 普通模拟跑很多次都碰不到溢出，绝不意味着风险为零——零命中时应用只给
> `3/n` 经验上界，不输出“零风险”结论。

## 快速开始

仅需 Python 3.10+ 标准库，无第三方依赖、无构建步骤。

```bash
# Web 应用（默认 http://127.0.0.1:8765）
./run.sh
# 或：python3 -m backend.cli serve --host 127.0.0.1 --port 8765

# 命令行对照估计
python3 -m backend.cli run --preset baseline --n 20000
python3 -m backend.cli presets

# 小状态系统的精确转移概率
python3 -m backend.cli exact scenario.json

# 测试
python3 -m unittest discover -s tests -v
```

数据目录由环境变量 `RAREEVENT_DATA_DIR` 控制，默认 `./data/tasks/`。

## 模型

每个时隙 `t`：

1. 抽样本时隙到达数 `a`；
2. 若 `q + a > C` → **本时隙首次溢出，路径立即终止**（先于服务判定）；
3. 否则 `q ← q + a`，再抽样服务完成数 `c`，`q ← max(0, q - c)`。

| 组件 | 可选模型 |
|---|---|
| 到达流 | 齐次泊松；两状态 MMPP（**突发到达**）；混合泊松（通用 pmf 似然比） |
| 服务过程 | 伯努利；确定性；两相位可停顿马尔可夫服务（**服务停顿**） |

内置预设：`baseline`（稀有泊松）、`bursty_mmpp`（突发）、`service_stall`（停顿）、
`extreme_weights`（强偏置下**权重塌缩**样例）、`tiny_exact`（精确核对小场）。

## 方法学关键点（与实现一一对应）

1. **似然比随路径状态逐段累计，而非按最终队列长度补权。**
   只倾斜到达机制；每个时隙对**实际抽样到的到达结果**累加对数似然比
   `log dP_nom/dQ_tilt`。MMPP 的相位切换、服务停顿的相位切换在两个测度下
   概率律相同，似然比贡献恒为 1。MMPP 权重使用**切换后的发射相位**
   （`engine.run_one_path`）。权重在对数空间累加，避免下溢。

2. **自适应选偏置与正式估计严格分离。**
   试运行（pilot）对候选倍率网格各用**独立随机流**评估相对误差，选定后
   **正式阶段机制固定**；试运行路径不进入正式统计。也可手动指定倍率
   （`extreme_weights` 用 `forced_tilt=3` 演示塌缩）。

3. **权重塌缩必须显式报告。**
   在线维护一阶/二阶矩，输出全体与命中路径内部的**有效样本量 ESS**；
   ESS 占比 < 1%、对数权重跨度过大、CI 相对半宽 > 100% 时标记为不可靠，
   并给出原因与不可靠区间（`engine.reliability`）。

4. **分片、取消与崩溃恢复的语义。**
   - 计算按 shard 分片，每片结束原子写盘（tmp + rename）：随机流完整状态、
     已**终止**路径的权重和与矩、收敛快照、费用计量；
   - 取消标志只在分片边界生效；**未跑完的路径直接丢弃，不记账**——
     既不会被当成“未溢出”，也不会被当成“已溢出”；恢复后随机流从断点延续；
   - 进程重启时 `running` 任务转为 `interrupted`，可继续恢复
     （恢复等价性有单元测试：分片跑与一次性跑的权重和逐位一致）。

5. **小状态系统精确核对。**
   对 `(队列长度, 到达相位, 服务相位)` 马尔可夫链做逐时隙精确转移，
   状态空间超 6000 直接拒绝；报告精确首次溢出概率、首次命中时隙分布、
   截断支撑导致的行和误差，并对模拟估计做 z 偏差与 CI 覆盖核对。

## 前端功能

- 调整容量 `C`、时域、路径数、分片、偏置倍率、种子；
- 查看试运行候选表与固定倍率选择；
- 两种模拟的估计、95% CI、ESS、命中数、RNG 调用/时隙/耗时等**费用对照**
  与收敛曲线（对数轴 + CI 色带，自绘 SVG，含悬停提示与表格孪生视图）；
- 查看**一条触发溢出的完整路径**：逐时隙到达、相位、队列、本时隙 log LR、
  累计 log W，以及命中路径对数权重直方图；
- 持久化任务列表：取消、崩溃后恢复、结果载入。

## 目录结构

```
backend/
  rng.py       从零实现的 xoshiro256** + splitmix64，泊松/几何/指数分布
  models.py    到达流（泊松/MMPP/混合）与服务（伯努利/确定/停顿）模型及似然比
  engine.py    单条路径、对数权重累加器、分片运行、自适应试运行、可靠性判定
  exact.py     小状态马尔可夫链精确首次溢出概率与估计核对
  presets.py   五个虚构预设场景
  store.py     原子持久化、后台线程、取消/恢复语义
  server.py    标准库 HTTP API + 前端静态托管
  cli.py       命令行入口
frontend/      原生 HTML/CSS/JS，无框架、无外部依赖
tests/         24 个 unittest：RNG、似然比恒等式、精确核对、塌缩、持久化、取消
```

## 随机数实现说明

`rng.py` 不使用 `random`/`numpy`：xoshiro256** 提供可完整导出/恢复的状态，
splitmix64 派生互不相关的子流（pilot、正式 IS、正式 Crude 各自独立）。
大速率泊松采用**自包含拒绝采样**：自适应离散拉普拉斯提议 + 显式求出的
包络常数，构造期在对数空间严格自检 `f(k) <= M·g(k)`，并有矩与尾部 CDF 的
数值测试兜底。
